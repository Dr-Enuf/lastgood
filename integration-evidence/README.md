# Evidence kept in this repository

Full raw PTY/TUI captures (terminal.raw and multi-hundred-KB spinner dumps) are omitted
here; each omission has a short `.omitted.txt` note. Desktop review packages under
`Hermes Plugin` still hold the complete raw files if a reviewer needs them.

Kept here:
- `v041-box-only`, `v041-review-fixes`, `v041-windows-test-fix`: standalone tests, review follow-ups, hashes
- `v041-live`: live PTY RESULTS and readable command excerpts (raw spinner dumps omitted)
- Independent review write-ups and host-gate summaries for v0.2.1–v0.4.0
- Test/doctor/validate/harness logs that are small enough to read

Personal filesystem paths in these files were generalized (`<USER_HOME>`, `<TEST_ROOT>`,
`<HERMES_HOME>`, `<DESKTOP>`, `<MACHINE>`) so the repo can be public. Counts and outcomes
were not changed.
